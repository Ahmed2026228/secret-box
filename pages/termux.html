موسوعة Kali

  • VirtualBox / VMware — الأسهل

إعداد ما بعد التثبيت

post.sh
sudo apt update && sudo apt full-upgrade -y
sudo apt autoremove -y && sudo apt autoclean
sudo apt --fix-broken install
sudo apt install -y virtualbox-guest-x11
lsb_release -a
uname -r
