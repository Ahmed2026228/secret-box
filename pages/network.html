أمن تطبيقات الويب

🛡️ OWASP Top 10 (2021)

💉

A01 — Broken Access Control

تجاوز صلاحيات الوصول — IDOR, Path Traversal, CORS.

🔐

A02 — Cryptographic Failures

فشل التشفير — بيانات غير مشفرة، خوارزميات ضعيفة.

💥

A03 — Injection

SQLi, NoSQLi, Command Injection, LDAP Injection.

🏗️

A04 — Insecure Design

تصميم غير آمن — مشاكل في المعمارية الأساسية.

⚙️

A05 — Security Misconfiguration

إعدادات خاطئة — منافذ مفتوحة، حسابات افتراضية.

📦

A06 — Vulnerable Components

مكونات قديمة — مكتبات وإضافات مصابة.

👤

A07 — Auth Failures

فشل المصادقة — كلمات مرور ضعيفة، جلسات.

📊

A08 — Data Integrity Failures

فشل سلامة البيانات — تحديثات غير موثقة.

📝

A09 — Logging Failures

فشل التسجيل — لا مراقبة، لا كشف.

🎭

A10 — SSRF

تزوير الطلبات من الخادم — استغلال خدمات داخلية.
